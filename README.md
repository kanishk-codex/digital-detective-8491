## Project Overview
This repository contains my completed work for the SnAI Diwali Independent Learning Assignment: *The Digital Detective*. The goal of this assignment is to explore how a modern computer functions—from hardware architecture and the operating system to the command-line interface, number systems, Python programming, Git version control, and computer networking.

Each mission represents a focused investigation into computer systems fundamentals, documented with practical observations, safe terminal experiments, code, and reflections.
